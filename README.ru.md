# TermGrid

English version: [README.md](README.md)

TermGrid — приложение для macOS в строке меню. Оно раскладывает окна любых приложений, в первую очередь терминалов, по сетке и позволяет менять размер ячеек мышью: тянуть разделители или края окон, без горячих клавиш.

## Статус

TermGrid — ранний MVP.

- Требуется macOS 14 или новее.
- Собирается и тестируется только с Command Line Tools. Проекта Xcode нет.
- Проверено живьём только на тестовых окнах TermGrid и в одной сессии мейнтейнера. Подгонка под шаг символов в Terminal.app не измерялась.

## Возможности

- Пресеты сетки (2 колонки, 3 колонки, 2 ряда, 2×2, 1+2, 2×3) на одном экране.
- Назначение окон в ячейки из меню или «Разложить автоматически».
- Перетаскивание разделителя меняет размер двух соседних ячеек сразу, во время движения мыши.
- Ресайз окна за внутренний край: соседний разделитель двигается, соседнее окно занимает освободившееся место. Внешний край сетки возвращает окно к размеру ячейки.
- Зазор между окнами: 0, 1, 2, 3, 4, 6 или 8 pt, по умолчанию 4 pt. Панели разделителей не меньше 6 pt по толщине и центрированы на зазоре.
- Подгонка под шаг символов для Terminal.app и iTerm2 включена по проекту. Она закрывает внутренние щели между соседними окнами терминалов, если недостаток меньше 40 pt.
- Раскладка сохраняется автоматически и восстанавливается кнопкой «Восстановить окна» в меню.
- Пока включён Стейдж-менеджер, меню показывает предупреждение.

## Требования

- macOS 14 или новее.
- Command Line Tools для Xcode. Полный Xcode не нужен: сборка идёт через `swift build`.

Проверить установку:

```bash
xcode-select -p
```

Если команда ничего не выводит или возвращает ошибку, установите их: `xcode-select --install`.

Выключите Стейдж-менеджер (см. раздел «Стейдж-менеджер»).

## Сборка

Из корня репозитория:

```bash
scripts/build-app.sh            # debug, по умолчанию
scripts/build-app.sh release    # release
```

Скрипт собирает продукт `TermGrid`, кладёт бинарь и `Resources/Info.plist` в `build/TermGrid.app` и подписывает приложение. Последней строкой он печатает путь к `build/TermGrid.app`.

## Тесты

```bash
scripts/test.sh --filter DividerTests
```

Аргумент `--filter` принимает имя suite из `Tests/GridCoreTests`. Имя берётся из объявления `struct`, а не из имени файла: suite `DividerTests` объявлен в файле `DividersTests.swift`. Все аргументы скрипт передаёт в `swift test`.

Скрипт нужен, потому что под одними Command Line Tools `swift test` со Swift Testing не работает (`no such module 'Testing'`). Скрипт добавляет флаги `-F` и `-rpath`, которые указывают на каталог фреймворков CLT. Вызывать `swift test` напрямую не нужно.

Полный прогон без `--filter` в локальном workflow не используется. Проверяйте suite, которые затрагивает ваше изменение.

## Запуск

```bash
open build/TermGrid.app
```

Запускайте приложение только через `open`. Бинарь `build/TermGrid.app/Contents/MacOS/TermGrid` из терминала не запускайте: право Accessibility проверяется у процесса, который запустил бинарь. Тогда право нужно выдавать терминалу, а не TermGrid.

Иконка появляется в строке меню. В Dock иконки нет (`LSUIElement`).

## Разрешения

TermGrid использует одно разрешение: **Универсальный доступ (Accessibility)**. Запись экрана (Screen Recording) не нужна: приложение не показывает содержимое окон.

1. Запустите `open build/TermGrid.app`.
2. macOS покажет системный диалог. Он только открывает Системные настройки. Включить переключатель в самом диалоге нельзя.
3. В Системных настройках откройте «Конфиденциальность и безопасность» → «Универсальный доступ» и включите TermGrid.
4. Если меню продолжает показывать онбординг после выдачи права, завершите TermGrid и запустите его снова через `open build/TermGrid.app`. В одном прогоне запущенный TermGrid не заметил право, выданное после старта, и записал «accessibility trusted» только после перезапуска.

Право теряется после каждой пересборки. Наиболее вероятная причина (не подтверждена): при ad-hoc подписи право привязано к хешу кода. Пересборка во время работающего экземпляра или переключение строки в Системных настройках, созданной другой сборкой, привязывает право к хешу, которого нет у запущенного процесса. После любой пересборки:

1. Завершите TermGrid.
2. Сбросьте право: `tccutil reset Accessibility local.termgrid.TermGrid` (см. раздел «Подпись»).
3. Запустите `open build/TermGrid.app` и выдайте право заново.

Пока право не выдано, меню показывает кнопку «Открыть настройки».

## Подпись

Скрипт сейчас подписывает приложение ad-hoc (`codesign --force --sign -`). Право Accessibility привязано к подписи. При ad-hoc каждая пересборка получает новую подпись. Выданное право после этого перестаёт работать, хотя переключатель в Системных настройках остаётся включённым.

План предпочитает стабильный self-signed сертификат, но `scripts/build-app.sh` его пока не использует и выбирает только ad-hoc. Путь с self-signed сертификатом не проверен: сертификата на машине разработки нет.

Пока сборка ad-hoc, после каждой пересборки сбрасывайте право и выдавайте его заново:

```bash
tccutil reset Accessibility local.termgrid.TermGrid
```

Затем запустите `open build/TermGrid.app` и выдайте право по шагам из раздела «Разрешения».

## Стейдж-менеджер

Выключите Стейдж-менеджер (Stage Manager) до использования TermGrid: Системные настройки → Рабочий стол и Dock → Стейдж-менеджер.

Пока он включён, macOS группирует окна по приложениям, переключает только между группами и переносит часть окон в боковую полосу. TermGrid не видит окна в этой полосе, поэтому раскладка ломается: окна могут сворачиваться или пропадать, а новые ячейки выглядят пустыми. Пока Стейдж-менеджер включён, меню TermGrid показывает предупреждение.

Причину указывает мейнтейнер проекта, и она согласуется с настройкой на машине разработки: `defaults read com.apple.WindowManager GloballyEnabled` выводит `1`. Повторная проверка с выключенным Стейдж-менеджером ещё не выполнена.

## Использование

Надписи в меню сейчас на русском языке.

- **Сетка**: выбор пресета, экрана и зазора, переключатель «Скрыть разделители». «Разложить автоматически» раскладывает окна, выбранные в списке окон; кнопка активна, только когда выбрано хотя бы одно окно. «Сбросить» очищает сетку. «Восстановить окна» возвращает сохранённую раскладку.
- **Ячейки**: для каждой ячейки можно разделить её по горизонтали или по вертикали, закрыть, вернуть откреплённое окно в сетку, повторить или убрать окно из ячейки.
- **Окна**: назначение окна в ячейку.

Тяните разделитель мышью, чтобы изменить размер двух ячеек по обе стороны. Тяните внутренний край окна, чтобы сдвинуть соседний разделитель. Тяните внешний край сетки, чтобы вернуть окно к размеру ячейки. Если вы сами переместили окно, оно открепляется от ячейки; «Вернуть в сетку» прикрепляет его снова.

Курсор ресайза появляется над разделителем, даже когда TermGrid не активное приложение. Подробности см. в разделе «Ограничения и известные проблемы».

## Ограничения и известные проблемы

- Окна на других Spaces не видны Accessibility. TermGrid их не раскладывает и не переносит между Spaces. Следуют ли панели разделителей за Spaces, не проверено.
- Полноэкранные окна пропускаются и не попадают в список окон.
- Сетка одна и находится на одном экране. Несколько мониторов в MVP не поддерживаются.
- Перемещение окна мышью открепляет его от ячейки.
- Стейдж-менеджер должен быть выключен. См. раздел «Стейдж-менеджер».
- Окно, у которого минимальный размер больше ячейки, получает статус `clamped` в логе и перекрывает соседние ячейки: при раскладке солвер не учитывает минимальные размеры. Не проверено на реальных приложениях.
- Не проверено: после «Разложить автоматически» с несколькими реальными окнами новая ячейка может выглядеть пустой. Мейнтейнер проекта связывает это со Стейдж-менеджером; повторная проверка с выключенным Стейдж-менеджером не выполнена.
- Не проверено: смена конфигурации мониторов может открепить окна до повторного apply. Для проверки нужен второй монитор.
- Не проверено: живой прогон приложения, остановленного SIGSTOP (с heartbeat главного потока), и окон Chromium и Electron.
- Панели-разделители работают на уровне `.floating`. Поверх неуправляемых окон они могут перехватывать клики в полосе зазора.
- Курсор ресайза использует приватное свойство соединения CoreGraphics `SetsCursorInBackground`. Приложение получает его через `dlsym` во время работы (`Sources/TermGrid/BackgroundCursor.swift`). Приватные API могут исчезнуть или измениться в новой версии macOS. Если символа нет, курсор остаётся системным, а разделитель подсвечивается при наведении.
- Вид курсора подтвердил на глаз мейнтейнер проекта. Автоматическая проверка `tgprobe` показала `matchesResizeLeftRight=false`, поэтому она не подтверждает вид курсора.
- Скорость живого ресайза замерена на собственных окнах TermGrid и на iTerm2. Terminal.app и браузеры не измерялись (`docs/spike-results.md`, раздел b).
- Наблюдение про настройку iTerm2 «Terminal windows resize smoothly» сделано в одном замере без записанного профиля и шрифта (`docs/spike-results.md`, раздел c). Проверьте настройку в своей версии iTerm2.

## Структура проекта

- `Sources/GridCore`: чистая логика раскладки (дерево ячеек, решатель рамок, разделители, ресайз за край, эхо-фильтр, политика подгонки, снимок раскладки). Импортирует только CoreGraphics и Foundation.
- `Sources/TermGrid`: приложение в строке меню (обнаружение и перемещение окон через Accessibility, панели разделителей, контроллер сетки, меню).
- `Sources/ProbeKit`: проверки Accessibility, общие для приложения и `tgprobe`. Инструмент отладки.
- `Sources/tgprobe`: утилита командной строки для проверок, которым нужен Accessibility. Запускается через бандл приложения.
- `Tests/GridCoreTests`: наборы тестов Swift Testing для `GridCore`.
- `Resources/Info.plist`: метаданные бандла.
- `scripts/`: сборка, тесты, проверка отсутствия комментариев и отладочные помощники (`probe.sh`, `selftest.sh`; им нужна отладочная сборка `build/TermGrid.app`).
- `docs/`: план реализации (`docs/plans/window-grid.md`) и результаты замеров (`docs/spike-results.md`).

## Участие в разработке

- Комментарии в коде не пишем. Это правило проекта. Обоснование кладите в сообщение коммита или в `docs/`. Проверка:

  ```bash
  scripts/check-no-comments.sh
  ```

  Скрипт печатает строки, которые нарушают правило, и завершается с кодом 1.
- Запускайте только тесты затронутых suite:

  ```bash
  scripts/test.sh --filter DividerTests
  ```

- Собирайте приложение перед ручной проверкой: `scripts/build-app.sh`.
- Пишите сообщения коммитов в формате conventional commits, как в текущей истории (например `feat(grid): ...`, `docs: ...`).
